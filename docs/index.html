Borrow on reputation, reviewed by validators

An Intelligent Contract on GenLayer that records loan requests, scores a borrower's public profile with AI consensus, and tracks repayment. The profile must prove it belongs to the borrower, and repayments only count once the lender confirms them. This is a Studionet prototype: no tokens or real funds move.
